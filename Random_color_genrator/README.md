
#  Random Color Generator

A simple and interactive web application that generates a random RGB color every time the user clicks the **Generate Color** button. The generated color is displayed as text and applied as the background color of the preview box.

---

##  Preview

When the button is clicked:

- A random RGB color is generated.
- The generated RGB value is displayed in the heading.
- The preview box changes its background to the generated color.

Example:

```
RGB(123, 45, 210)
```

##  How It Works

1. The user clicks the **Generate Color** button.
2. JavaScript generates three random values:
   - Red (0–254)
   - Green (0–254)
   - Blue (0–254)
3. These values are combined into an RGB color.
4. The generated RGB value is displayed in the heading.
5. The background color of the preview box changes to the generated color.
